# Systeme visuel du frontend

Le frontend prend pour reference la direction visuelle du kit Preclinic fourni dans Figma.

## Principes retenus

- navigation laterale blanche et compacte ;
- barre superieure avec recherche et profil ;
- fond d'application gris tres clair ;
- cartes blanches avec bordures fines ;
- bleu indigo comme couleur principale ;
- accents turquoise, vert, orange et rose pour les indicateurs ;
- densite adaptee a un outil administratif ;
- mise en page responsive pour tablette et mobile.

## Tokens principaux

| Token | Valeur | Utilisation |
|---|---|---|
| Primary | `#343CAC` | Navigation active, boutons et graphiques |
| Cyan | `#12BDD2` | Statistiques et donnees terminees |
| Green | `#24AD72` | Succes, paiement et progression |
| Orange | `#F28B45` | Alertes moderees et file d'attente |
| Background | `#F4F7FB` | Fond de l'application |
| Border | `#E7EBF2` | Separateurs et contours |
| Text | `#172033` | Texte principal |

Les futurs ecrans d'authentification, patients, rendez-vous et consultations doivent reutiliser ces tokens.
